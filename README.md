# Druthers.

A modern, distraction-free weighted decision matrix tool based on the weighted scoring method. Compare multiple options against custom weighted criteria and receive a data-driven, ranked recommendation.

## Features

- **Multi-Decision Management**: Create, switch, and delete multiple decisions from a collapsible sidebar menu.
- **Dynamic Criteria & Weights**: Add options and customizable criteria with 1–5 importance weights.
- **Editable Scoring Grid**: Rate option × criterion pairs from 1–10 in a responsive table.
- **Weighted Rankings**: Instant calculation of weighted scores normalized as percentages, with visual bar indicators.
- **Calculations Toggle**: Optional breakdown view for inspecting the exact arithmetic.
- **Ocean Sorbet Palette & Glassmorphic UI**: Ambient lighting, backdrop filters, and custom serif typography.
- **Dark & Light Themes**: Quick toggle with persisted user preference.
- **100% Client-Side Privacy**: All data auto-saves to `localStorage`. Zero trackers, zero external database calls.
- **Export & Import**: Export decisions to portable JSON or import previously saved decisions.

## Tech Stack

- Plain HTML5, CSS3, Vanilla JavaScript
- No build steps or frameworks required
- Deployed on Cloudflare Pages
